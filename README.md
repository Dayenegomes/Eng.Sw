## 1. Que problema vocês resolvem?

Ocorrem problemas para alocar as salas, principalmente para acompanhar quais estão ocupadas ou com problemas, como falta de ar-condicionado.

## 2. Para quem?

- **Monitores de corredor das salas** — atualizam o estado das salas sob sua responsabilidade
- **Coordenador** — tem acesso e acompanha todas as salas do setor

## 3. Por que a solução vale a pena?

Alocar salas com agilidade, acompanhar problemas para manutenção e auxiliar a comunicação dos monitores.
